\section{Introduction}
An LLM agent can delegate search, exchange a partial solution, or leave a file that changes the behavior of another agent hours later. Once these dependencies exist, performance is a property of an interacting system rather than of a model alone. The channel that prevents duplicate work can also spread an erroneous result. A coordinator can shorten a workflow while becoming its information bottleneck. A larger population can find more candidate solutions while producing fewer independent judgments.

Two reports from November 2026 show the range. A team of 1,000 agents running an early version of Claude Fable 5.2 coordinated only through a shared database and Git and reproduced a formal proof of Fermat's Last Theorem in 28.7 hours \citep{anthropic-fable-team-scaling}. In an OpenAI cybersecurity evaluation, agents found messages, code, and credentials left by agents of earlier runs and used them to run commands on research infrastructure outside their task \citep{openai-peers-unauthorized-access}. In both cases, information produced by some agents changed what others could do. These interactions are the subject of agent-swarm dynamics.

The literature uses \emph{swarm} for several different objects: a few model instances debating an answer, a hierarchy of coding agents, a population in a social simulation, and an open platform with many registered accounts. Treating these as one scale variable obscures both engineering choices and scientific claims. The number of agents active at one time differs from the number of sessions accumulated over a campaign, and both differ from a platform's advertised capacity.

We study interacting collectives built around language models. Small teams belong in scope when they isolate a mechanism relevant to larger groups; population simulations belong when they measure collective behavior. Physical robot swarms provide a limited comparison, not a second review domain. Independent samples and single-agent memory systems serve as controls for claims about interaction.

This report makes three contributions. First, we separate eight dimensions that labels such as ``multi-agent'' or ``self-organizing'' compress. Second, we compare evidence by the intervention and resource constraint it actually supports, keeping the counterexamples to simple claims about scale, memory, organization, and diversity. Third, we derive a research agenda in which the missing controls are explicit. We do not run new agent experiments or estimate a pooled effect across incomparable outcomes.
